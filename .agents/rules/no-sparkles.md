# Global Rule: No Sparkles or Sparks Anywhere on Website

- **Zero Sparkles**: Sparkle icons, particles, emojis (`✨`), and animations are strictly prohibited across all pages and components.
- **Icon Usage**: Never import `Sparkles` or `Sparkle` from `lucide-react` or any other library.
- **CSS & Classes**: Do not introduce CSS rules, animations, or class names with `sparkle` or `spark`.
- **Allowed Icons**: Use professional, purpose-driven icons like `Compass`, `ShieldCheck`, `Award`, `TrendingUp`, `CheckCircle2`, `Zap`, `Search`.
